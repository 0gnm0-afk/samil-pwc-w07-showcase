# TASK-044 AI 보완 질문과 영업 회신 후 재판단

기존 운영 건은 NIM 연결에 성공했지만 계좌 차이의 사유를 뒷받침하는 현재 회신 없이 진행 권고를 반환했다. 앱이 인용과 진행 조건을 검사해 권고 수용을 막았고 화면 설명은 빠진 자료를 구체적으로 알려주지 않았다. 모델 내부에서 어떤 추론이 결론에 영향을 줬는지는 확인할 수 없다.

AI에 원본에서 확인된 차이와 연결된 회신을 제공해 추가 질문과 회신의 충분성을 판단하게 했다. 원본 모드에서 검증에 실패한 응답은 사유를 붙여 같은 자료로 한 번 다시 판단하게 한다. 두 번째 결과도 유효하지 않으면 정확한 상태와 필요한 자료를 표시한다. 앱이 보완 또는 진행이라는 AI 결론을 생성하지 않는다. 원본, 인용, 현재 자료 버전, 권한, 결재 및 지급 조건 검사는 유지했다.

원본 검토에서 AI의 보완 질문은 회계에 먼저 표시된다. 질문 옆에 내용을 고칠 수 있는 요청 폼을 배치했고, 회계가 전송하면 영업 작업 한 건이 열린다. 이미 발송된 보완 건도 이어서 처리한다. 영업 회신 저장은 새 자료 버전의 검토를 생성한다. 화면 조회와 역할 변경은 별도 AI 호출을 만들지 않는다.

최종 코드로 가상기업의 계좌 차이 묶음을 접수하고 회계·영업 화면에서 검증했다. 최초 진행 권고는 회신 인용 누락으로 검증에 걸렸다. 자동 재판단에서 실제 NIM이 보완 질문을 반환했고, 회계 화면에서 질문을 바로 보내 영업 화면에 도착한 내용을 확인했다. 영업이 수금계좌와 장려금 정산계좌의 용도 차이를 설명한 모의 회신을 등록하자 새 버전의 실제 NIM이 원본 세 건과 회신을 인용해 진행을 권고했다. 회계 화면에 ‘AI 권고 · 결재 요청 가능’과 수용 버튼이 표시됐다. 이번 시연은 권고 표시까지 확인했다. 실제 NIM 응답 및 재검토 기록(비공개 보관) · [회신 후 회계 화면](../화면/03_보완회신후_AI재판단.png)
