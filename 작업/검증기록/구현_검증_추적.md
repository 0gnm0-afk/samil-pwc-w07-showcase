## 관찰한 실패와 수정

1. AXHub 인증의 샌드박스 초기 점검 실패: 네트워크·자격 저장 접근 가능한 환경에서 갱신 후 앱/DB 읽기 성공. 새 로그인으로 우회하지 않았다.
2. 로컬 서버와 외부 실행 프로세스의 localhost 접근 차이: 동일 네트워크 실행 환경과 명시적 `127.0.0.1:8081`로 검증했다.
3. PostgreSQL JSONB의 필드 순서가 동일 은행 회신 비교에 영향을 줌: 해시 전에 객체 키를 재귀 정렬했다. SQL 저장·재조회 후 동일 회신 재입력 회귀 검증을 추가했다.
4. NIM이 `scope`를 ID 목록 대신 설명 문자열로 반환함: 실제 HTTP 200이었지만 서버가 적용 거부하고 수동 검토로 연결했다. 계약에 입력별 허용 ID와 구체적인 예를 제공한 뒤 실제 호출에서 통과했다. 허용 범위 검사를 완화하지 않았다.
5. 영속 로컬 PGlite 폴더를 중복 프로세스로 열고 강제 종료한 개발 실행이 재시작에 실패함: 해당 폴더를 보존하고 검증은 독립 메모리 SQL 인스턴스로 수행했다. 이것을 AXHub 영속성 통과로 계산하지 않는다.
6. 은행 차이가 먼저 기록된 뒤 새로 접수한 관련자 건도 보류하도록 공통 재검사에 미확인 실적 범위 검사를 추가했다. 단위 회귀 검증 통과.
7. 계좌 변경 이전 증빙으로 새 계좌를 확인 처리하지 못하도록 증빙 종류·입력 적용 시점 검사를 추가했다. 정상 새 계좌 증빙과 보완 회신으로 재상신하는 HTTP 검증까지 다시 통과했다.

## 외부 변경 이력 · 시점별 기록

NVIDIA 단일 외부 주소 선언 후 운영 서버 실제 NIM 호출이 성공했다. 두 번째 AXHub 실행은 24개 검증을 통과하고 AC-08 변경 사례의 비정형 JSON을 거부하여 중단됐다. 해당 결과는 수동 검토로 연결되었고 자동 지급은 발생하지 않았다. NVIDIA의 [JSON 응답 모드 안내](https://docs.nvidia.com/nim/large-language-models/2.0.10/get-started/advanced/get-started-nemotron-3.5-lightning.html)에 따라 `response_format: json_object`를 추가하고 인용·범위·역할 검사는 그대로 유지했다. 로컬 실호출 HTTP 200과 13개 회귀 검증을 통과했다. 날짜가 계좌 패턴으로 마스킹되던 문제도 수정하여 유효한 ISO 날짜는 보존하고 계좌·비밀은 계속 마스킹한다.

서버 인스턴스 교체 후 새 독립 계정 세션에서 AC-01 상태 전체 해시가 동일했다(지급 지시 3·최종 회신 3·이벤트 13). 검증 공간 초기화는 접수 1건을 0건으로 되돌리고 원본 파생 지급 240건을 유지했다. `AXHub_재시작_검증.json`, `AXHub_초기화.json` 참조.

DB 설정을 보완한 `0487c14`의 운영 배포 `e9f761c5-161b-40b6-b9a5-f06f7da92189`는 공식 verify에서 성공했다. 새 주소는 https://app-q1zb.axhub.app 이며 기존 .page 주소의 307 연결과 최종 HTTP 200을 확인했다. 공개 체험의 독립 공간·권한 차단·3건 모의 지급 대사는 통과했다. 첫 AXHub AC 실행은 AC-01·01a·02 통과 후 실제 NIM에서 시간 초과로 중단됐다. 동일 키·모델의 로컬 호출은 HTTP 200이므로 서버 외부 연결을 우선 가설로 삼아 공식 network.egress 설정에 NVIDIA의 단일 HTTPS 호스트를 명시한다. 아직 NIM 통과로 판정하지 않는다.

첫 구현 배포는 이미지 빌드까지 성공했으나 `DATABASE_URL` 미주입으로 시작에 실패했다(배포 `28cd8f5d-f88d-4a03-b2a3-5954d12c2a3e`, 코드 `999345589a3aa83668ffb570e4c36617ed412b42`). 공식 배포 기준에 따라 매니페스트에 `database.engine: postgres`를 추가했다. 앞선 작성자 설정 오류 시 이전 문서 커밋이 먼저 전송된 배포 `98229ffb-9a03-4cf4-85ed-b1f634dd418e`는 static/docker 불일치로 준비 단계에서 중단됐다. 실패를 성공 검증에 포함하지 않는다.

사용자는 개인별 체험 공간+시연 역할 선택을 확정했고, 영구 전환·배포·비밀 설정 등록을 명시 승인했다. 2026-11-11 18:25 KST 공식 CLI로 기존 앱의 Docker 전환과 NVIDIA_API_KEY·W07_ACCOUNT_HASHES 비밀 설정 등록을 완료했다. [공개 체험 검증](공개체험_검증.md)과 독립 계정 기반 AC-05는 유지한다. 이 시점의 서버 구현 배포와 실제 AXHub 검증은 진행 중이며 성공으로 계산하지 않는다.

NIM 합성 증빙 전송은 실제 payload 검사 후 실행했다. 사용자 키는 DPAPI에서 메모리로 읽고 로컬 비공개 설정에만 주입했다. Git 후보 75개 파일의 정확한 키·역할 비밀번호·원본 전체계좌 검사에서 노출 0건이었다. 검사는 최종 배포 후보에서 다시 수행한다.
