# 로그인 없는 개인별 공개 체험 검증

2026-11-11 · 로컬 구현 결과. 기존 AXHub 앱의 영구 전환·배포 승인 대기 중이며 이 문서는 AXHub 검증 증거가 아니다.

사용자 결정: 로그인 없는 개인별 체험 공간과 시연 역할 선택. 구현지시서 12절에 추가했다. 실제 독립 사용자 권한 검증은 기존 배정 계정으로 유지한다.

| 검증 | 관찰 결과 | 판정 |
| --- | --- | --- |

| 실제 화면 | 무로그인 입장 → 접수 → 회계 역할 전환, 3,888,097원 및 시연 고지 확인 | PASS |

서버 검증: `app/test/public-demo.test.mjs`(공개본에는 없음). 실제 브라우저 관찰: 공개체험-브라우저.json(비공개 보관). 화면 캡처는 브라우저 도구 시간 초과로 저장되지 않았으며, DOM 관찰을 화면 증거로 기록했다. 이 항목을 스크린샷 성공으로 표시하지 않는다.

별도 이력 검증 `app/test/history.test.mjs`에서 변경 전후 값·보류 해제·확인 실적의 보존, 이미 해결한 충돌의 동일 회신 재입력 멱등성을 통과했다.

후속 작업 완료: 사용자의 명시 승인 후 앱 전환·서버 비밀 등록·운영 배포·AC 26개·공개 체험·재시작 영속성·초기화 후 재실행을 완료했다. 이 문서는 당시 로컬 검증 기록이며 최종 상태는 AXHub 최종 검증(비공개 보관)을 따른다.
